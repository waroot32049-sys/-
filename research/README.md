# Classroom Research Assistant

เว็บแอปช่วยจัดทำวิจัยในชั้นเรียนตามคู่มือที่ผู้ใช้แนบ โดยจัด workflow เป็น A-P-A-O-R และรายงานฉบับเต็ม 5 บท

## URL ใช้งาน
เมื่อ GitHub Pages ของ repository นี้เปิดจาก branch `main` / root:
https://waroot32049-sys.github.io/-/research/

## โครงสร้างที่รองรับ
- วิเคราะห์ปัญหาแบบ Input / Process / Product
- เลือกสาเหตุที่ครูสามารถแก้ไขได้และกำหนดวิธีแก้/นวัตกรรม
- กำหนดหัวข้อวิจัยจาก “ศึกษาอะไร / กับใคร / อย่างไร”
- บทที่ 1: ความเป็นมา วัตถุประสงค์ สมมติฐาน ขอบเขต นิยามศัพท์ และประโยชน์
- บทที่ 2: เอกสารและงานวิจัยที่เกี่ยวข้อง พร้อมค้น metadata จาก ThaiJO
- บทที่ 3: ประชากร/กลุ่มตัวอย่าง เครื่องมือ การตรวจคุณภาพ การเก็บข้อมูล และสถิติ
- บทที่ 4: ผลการวิเคราะห์ข้อมูล พร้อมคำนวณ Mean, SD และ paired t เบื้องต้น
- บทที่ 5: สรุปผล อภิปรายผล และข้อเสนอแนะ
- บรรณานุกรมและส่วนอ้างอิง
- พิมพ์ A4 หรือ Save as PDF เป็นรายงานฉบับเต็ม

## ThaiJO
แอปใช้ OAI-PMH public metadata ของ ThaiJO เพื่อค้นงานที่เกี่ยวข้องและเพิ่มรายการอ้างอิงโดยอาศัย metadata ที่พบจริงเท่านั้น

ข้อจำกัด: เบราว์เซอร์อาจถูกจำกัดด้วย CORS/rate limit ของต้นทาง การค้นผ่าน OAI-PMH ไม่เท่ากับ full-text search ทั้งฐานข้อมูล จึงควรตรวจต้นฉบับ ชื่อผู้แต่ง ปี วารสาร DOI/URL ก่อนใช้ในรายงาน

หน้าค้นอย่างเป็นทางการ:
https://www.tci-thaijo.org/th/articles/advanced

## เครื่องมือวิจัย
ตัวช่วยในแอปรองรับ:
- IOC
- Cronbach's alpha
- ค่าความยาก p
- ค่าอำนาจจำแนก r
- สถิติพื้นฐานจากคะแนนก่อน/หลัง

ค่าตัดต่าง ๆ ในหน้าตัวช่วยเป็นแนวทางทั่วไป ไม่ใช่มาตรฐานบังคับ ผู้วิจัยต้องเลือกเกณฑ์ให้สอดคล้องกับชนิดเครื่องมือ ระเบียบวิธีวิจัย และแหล่งอ้างอิงที่ตรวจสอบได้
