# ระบบบริหารงานงบประมาณโรงเรียน

เว็บแอปสำหรับบริหารงานงบประมาณของโรงเรียนบ้านจรูกแขวะ รองรับมือถือและคอมพิวเตอร์

## ฟังก์ชันหลัก
- Dashboard ภาพรวมงบประมาณ
- แผนงานและโครงการ พร้อมความก้าวหน้า
- ทะเบียนรายรับ-รายจ่าย
- ระบบจัดซื้อจัดจ้าง
- งานที่ต้องดำเนินการ
- รายงานสำหรับผู้บริหาร
- ส่งออก/นำเข้าข้อมูล JSON
- รองรับ PWA และใช้งานออฟไลน์บางส่วน

## การเก็บข้อมูล
เวอร์ชันปัจจุบันเก็บข้อมูลใน Local Storage ของเบราว์เซอร์ จึงเหมาะกับการใช้งานภายในเครื่องเดียวหรือใช้เป็นต้นแบบพร้อมใช้งานทันที ควรสำรองข้อมูลด้วยเมนู "ส่งออกข้อมูล" เป็นประจำ

## การเผยแพร่
Repository มี GitHub Actions workflow สำหรับ GitHub Pages อยู่ใน `.github/workflows/pages.yml`

หาก Pages ยังไม่เปิดใน repository ให้เข้า Settings > Pages > Source และเลือก GitHub Actions
