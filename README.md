# ระบบบริหารงบประมาณและติดตามแผนปฏิบัติการ 2569

เว็บแอปของโรงเรียนบ้านจรูกแขวะที่สร้างจากข้อมูลในแผนปฏิบัติการประจำปีงบประมาณ 2569

## ฟังก์ชัน
- ทะเบียนโครงการหลัก 24 โครงการตามหน้ารับรอง
- แยก 4 ฝ่าย: วิชาการ 8, งบประมาณ 3, บุคคล 2, บริหารทั่วไป 11
- Dashboard กรอบจัดสรรและความก้าวหน้า
- บันทึกความก้าวหน้ากิจกรรม ตัวชี้วัด และหลักฐาน
- เช็กลิสต์กิจกรรมตามแผน
- แนบภาพหลักฐานสูงสุด 6 ภาพต่อโครงการ
- บันทึกรายรับ-รายจ่ายจริงและผูกกับโครงการ
- พิมพ์รายงานโครงการ A4 และบันทึกเป็น PDF จาก Print dialog
- พิมพ์รายงานสรุปทั้งแผน
- สำรอง/กู้คืนข้อมูล JSON
- PWA และ cache สำหรับใช้งานต่อเนื่อง

## ข้อมูลจากต้นฉบับ
ในไฟล์แผนมีบางรายการที่เลขลำดับ/จำนวนโครงการ/ปีในหัวข้อไม่สอดคล้องกัน ระบบจึงมีหน้า “ตรวจสอบข้อมูลจากไฟล์” และไม่แก้ข้อมูลต้นฉบับแบบเงียบ ๆ

## การเก็บข้อมูล
ผลการดำเนินงาน รายการการเงิน และภาพหลักฐานเก็บใน Local Storage ของเบราว์เซอร์เครื่องที่ใช้งาน ควรดาวน์โหลดไฟล์สำรอง JSON เป็นระยะ
